# python-file-classifier.
Python automation script to categorize audio files by decade and genre.
## Description
This project automates the organization of large media directories. It was specifically designed to process a large collection of audio tracks from the 1970s to 1999, restructuring chaotic folders into a clean, logical hierarchy based on decades and genres.

## Features
* Automated directory scanning and file classification.
* Efficient file management using Python libraries (`os`, `shutil`).
* Significantly reduces manual sorting time for large data structures.

## Skills Demonstrated
* Python Scripting & Automation
* File system operations
* Data organization and logical structuring
